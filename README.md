# intro
**안정성과 비용 효율성을 지향하는 신입 백엔드 개발자**입니다.  
단순 기능 구현을 넘어, **운영 관점의 인프라 설계와 보안 표준**을 실천하는것이 목표입니다.

---

### Tech Stack

**[ Language & Framework ]**
* **Backend:** Java 21, Spring Boot 3.4, Spring Framework
* **ORM/Legacy:** JPA (Hibernate), MyBatis, JSP
* **Frontend:** Node.js 기반 프론트엔드 연동 경험

**[ Infrastructure & DevOps ]**
* **Cloud:** AWS (VPC, EC2, RDS, S3, IAM)
* **Container:** Docker
* **CI/CD:** GitHub Actions 기반 자동화 파이프라인

**[ Database & Security ]**
* **DB:** MySQL, Oracle Database
* **Security:** **OWASP Top 10** 기반 보안 설계 (SQLi, SSRF 방어)

### 📂 Projects

#### 1️⃣ Aura3D – On-Demand 서버 모니터링 엔진 (2025.12 ~ 2026.01)
> **Java 21의 신기술을 활용한 고성능·저비용 관제 엔진**
* **Core:** Java 21 **Virtual Threads**를 활용한 대규모 I/O 병렬 처리 엔진 구현
* **AI:** **Google Gemini API** 연동을 통한 장애 로그 분석 및 조치 가이드 생성
* **Optimization:** 상태 변화 감지 로직 설계를 통해 **AI API 호출 비용 약 90% 절감**
* **Deployment:** Docker 및 GitHub Actions를 활용한 CI/CD 환경 구축

#### 2️⃣ AWS Security & Infrastructure (2025.11 ~ 2025.12)
> **보안 표준을 준수하는 클라우드 아키텍처 설계**
* **Network:** VPC 내 Public/Private Subnet 분리를 통한 인프라 보안 강화
* **Identity:** IAM 사용자/역할 기반의 **최소 권한 원칙(PoLP)** 적용
* **Security:** Security Group 및 NACL 설계를 통한 계층별 접근 제어

#### 3️⃣ MZ Project – 맛집 검색 플랫폼 (2023.09 ~ 2024.01)
> **Spring Legacy 기반의 웹 서비스 구축 및 배포**
* **Feature:** MyBatis 기반 DB 연동 및 카카오 맵 API를 활용한 위치 서비스 구현
* **Security:** Prepared Statement 적용으로 **SQL Injection** 방어
* **Infra:** AWS EC2/RDS 환경 수동 구축을 통한 인프라 기초 역량 습득
